## 🔬 Deep Dive — Featured Models

</div>

<table>
<tr>
<td width="50%" valign="top">

### 💹 NDVF — Ticker Classification
Predicts which of **10 companies** (AAPL, AMD, AMZN, GOOGL, JPM, META, MSFT, NFLX, NVDA, TSLA) a financial news article is about, from a corpus spanning **January 2015 → present**.

**Pipeline:** ingestion → text preprocessing → structural/sentiment/NER/topic features → correlation analysis → SBERT embeddings (384-dim) → PCA (→50-dim) → model comparison (scikit-learn + LazyPredict + XGBoost) → feature importance → best-model save.

**Result:** `97%` test accuracy — the highest-scoring model in the whole pipeline.

*Planned extension: narrative/semantic drift scoring over the 2015–present window as a volatility signal — not yet shipped.*

</td>
<td width="50%" valign="top">

### 🧠 Bi-LSTM News Classifier (V7)
The deep-learning counterpart to the classical News Category Classification project — same task (predict category from title), solved with a **GloVe-initialized, 2-layer Bidirectional LSTM**.

**Architecture:** 256 hidden dims · triple pooling (attention + mean + max) · LayerNorm/GELU classifier head · Focal Loss + label smoothing + class-balanced sampling for imbalance.

**V4 → V7:** splitting `Business/Markets` back into two classes and augmenting every category to ~1,800 samples took test accuracy from **79.13% → 87.44%** (train: 98.79%) — an **+8.31 point** jump driven by data-level fixes, not architecture changes.

</td>
