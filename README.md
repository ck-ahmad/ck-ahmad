## About

Final-year Computer Science student at **FAST NUCES** (2023–2027) with production experience across nine organizations, spanning AI/ML engineering, backend development, and data engineering. My work centers on building and shipping machine learning systems — from raw data collection through preprocessing, embeddings, ML, and DL — and wiring them into reliable, API-driven backends, plus ETL/ELT pipelines and warehouse modeling on the data-engineering side (Databricks, Snowflake, Azure). I maintain two published PyPI packages, contribute to open source through **Google Summer of Code 2026**, and sit on the **Board of Directors at Afrium**, Pakistan's first undergraduate AI research organization.

**Top skills (LinkedIn):** Data Pipelines · Azure Databricks · SQL

**Currently:** building `NDVF` — a narrative drift-induced volatility forecasting system using SBERT semantic drift signals over a PostgreSQL + ChromaDB + XGBoost pipeline — alongside ML pipeline work at LimeoX and data-engineering work at Helmes.
